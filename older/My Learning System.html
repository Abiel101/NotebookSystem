See the bigger picture.

06 / The System

The whole learning loop.

1

Learn

Class, textbook, course, HTB, lab, or another learning source.

2

Take notes

Use the active notebook. Write what matters in my own words.

3

Practice

Homework, problems, commands, labs, investigation, or projects.

4

Understand

Explain it to myself and identify what I still do not understand.

5

Map + connect

Place important ideas into the bigger picture and connect them across subjects.

6

Archive + revisit

Preserve completed work and return to the map when I need the bigger picture again.

07 / Personal Rules

When I forget how I want to learn.

  • Do not build a beautiful system that prevents me from learning.
  • Do not copy information just to make the notebook look complete.
  • Write in my own words whenever possible.
  • Use mistakes and questions as information about what I need to learn.
  • Practice matters — especially for cybersecurity.
  • Archive as I go so the active notebook stays small.
  • The mind map is for understanding and connections, not duplication.
  • Obsidian is a tool for the map, not the purpose of the map.
  • The system can change if I discover a better way to learn.
My simplest reminder Learn it → Work it → Understand it → Map it → Connect it → Archive it → Revisit it.
